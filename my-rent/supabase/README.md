# مزامنة إداراتي بين الأجهزة (DW-018 · DW-019)

**DW-019:** المشروع مدمج بالتطبيق: `idarati` (`zqnitovbkgvbeuzzglzc`، ap-northeast-1، منظمة «ads»). الرابط والمفتاح العام (anon) بملف `my-rent/.env`.
المستخدم يسوي حساب بإيميل وكلمة سر من الإعدادات، وكل حساب له مساحة وحدة خاصة فيه (`families_one_per_owner`).
بدون حساب: البيانات على الجهاز بس، وما يطلع أي طلب للسحابة.

### باقي على المالك (من لوحة Supabase)
- **Authentication ← URL Configuration ← Site URL** = رابط التطبيق على Vercel (رابط تأكيد الإيميل يرجع له؛ بدونه يفتح localhost بعد التأكيد، والحساب يتأكد عادي).
- **SQL Editor:** الصق دالتي `delete_family` و `leave_family` من `setup.sql` (أداة الربط تطلب تأكيد يدوي لأي أمر فيه حذف، فما انطبقت). الباقي كله منطبق ومفحوص.

## شلون تشتغل

- كل تعديل (دفعة، مصروف، تراجع…) صف واحد بجدول `events`. كل جهاز يعيد تطبيقها بالترتيب، فما فيه تعارض بين جهازين.
- **RLS:** العضو يقرأ ويضيف أحداث عائلته بس. ما فيه تعديل ولا حذف لأي حدث. غير الأعضاء يشوفون صفر.
- بدون نت: التطبيق يشتغل عادي، والتعديلات تنتظر بطابور وتنرفع لما يرجع النت (بدون تكرار).
- «احذف كل البيانات» بالإعدادات يمسح **الجهاز بس**. حذف بيانات العائلة من السيرفر زر منفصل للمالك.
