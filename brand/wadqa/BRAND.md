# هوية WADQA (الشركة)

> مقترح بانتظار اعتماد المالك (DW-071). **فرضية الاسم:** «ودقة» = ودق (قطر المطر) + «و دقة». إذا المعنى غيره، الرمز يتعدّل. مصدر كل الملفات: `python3 brand/wadqa/build.py && (cd sports-hub-app && PW=$PWD/node_modules/playwright node ../brand/wadqa/render.cjs)`.
> الشركة هي WADQA، والتطبيق يبقى **Sports Hub** بهويته (`sports-hub-app/brand/`). ما نغيّر اسم التطبيق.

## الرمز
**قطرة تصوّب على نقطتها**: قطرة مفرغة، بداخلها حلقة ونقطة (دقة). اسم ومعناه بشكل واحد. بدون الأحمر (خاص بـ Sports Hub) وبدون خط منتصف (كان يشبه كرة بوكيمون).

| الملف | الاستخدام |
|---|---|
| `mark.svg` / `mark-512.png` | الرمز على الداكن |
| `mark-light.svg` | الرمز على الأبيض/الورق (`#00788A`) |
| `mark-mono.svg` | لون واحد (`currentColor`): ختم، طباعة، تطريز |
| `mark-small.svg`, `favicon-32.png` | ≤ 32px: حلقة أسمك بدون تفاصيل |
| `logo-horizontal(.light).svg` | الرمز + WADQA، الحروف مسارات |
| `logo-arabic(.light).svg` | «ودقة» + WADQA، الرمز يمين (RTL)، مسارات |
| `icon-512.svg/png`, `icon-maskable-512.*` | أيقونة (الـmaskable داخل 60% الوسط) |
| `wadqa-board.png` | لوحة الهوية |

## الألوان والخط
| اللون | HEX | الاستخدام | التباين |
|---|---|---|---|
| ليل | `#05080F` | الخلفية | — |
| سماوي | `#00E5FF` | الرمز على الداكن | 13.0:1 |

| حبر | `#EAF6FF` | النص على الداكن | 18.2:1 |

الخط: **Tajawal 800** (عربي ولاتيني)، WADQA بتباعد حروف واسع.

## القواعد
- مساحة فاضية حولها ≥ ربع عرض الرمز. أصغر حجم: 16px (نسخة small)، والأفقي 96px عرضاً.
- لا أحمر، لا تدرج، لا ظل، لا إمالة، لا صورة مزدحمة خلفه.
- لا نستعمل المعنى كوعد بميزة بالتطبيق؛ هو معنى اسم فقط.
