# هوية «دلمون» (DILMUN STUDIO)

**الاسم:** دلمون — اسم البحرين القديم. **الفكرة:** قوس بوابة + لؤلؤة = بوابة البحرين ولؤلؤتها.
**الاسم الرسمي المقترح:** دلمون للبرمجيات · Dilmun Studio. التسمية القانونية تنتظر فحص «سجلات» (توفر الاسم) وفحص العلامة التجارية.

| الملف (`out/`) | متى |
|---|---|
| `mark-app-icon` (.svg + 1024.png) | الأساسي: بروفايل، أيقونة |
| `mark-on-dark/light`، `mark-mono-ink/white` | حسب الخلفية؛ الأحادي للطباعة والتطريز |
| `stamp-ink/gold-on-dark/bone-on-dark` (.svg + 1024.png) | الختم: مستندات، عقود، فواتير |
| `lockup-horizontal/stacked-light/dark.png` | الشعار + الاسم |
| `business-card-front/back.png` | بطاقة 1050×600 (بيانات التواصل مكانها [ ]) |
| `letterhead-A4.pdf` | ورقة رسمية |
| `brand-board.html/.png` | لوحة الهوية |
| `tokens.css` | متغيرات CSS |

## الألوان
| | Hex | قاعدة |
|---|---|---|
| حبري Ink | `#0B1514` | الأساسي |
| عاجي Bone | `#F2EBDD` | نص على الحبري 15.6:1 |
| ذهبي Gold | `#C8A04A` | لمسة وحدة؛ نص حبري عليه 7.6:1؛ **ممنوع نص ذهبي على فاتح** (2.1:1) |
| ذهبي غامق | `#7A5A12` | نص ذهبي على العاجي 5.4:1 |
| سليت `#1C2B2A` · ضبابي `#8FA09C` | أسطح · نص ثانوي (6.8:1) |

**الخط:** IBM Plex Sans Arabic 700 (نفس حياتي). الاسم «دلمون» فوق وتحته DILMUN STUDIO بمسافة 0.14em.
**ممنوع:** تغيير الألوان، مد، ظل، تدوير. **المنتجات** لكل واحد هويته (حياتي بحري/مرجاني)، ودلمون بالفوتر: «من دلمون».
**الختم هوية مو ختم قانوني:** بدون رقم سجل. لو سجّلت، يضاف الرقم بعد المحامي.
إعادة البناء: `PW=<مسار playwright> node company-brand/build.js`
