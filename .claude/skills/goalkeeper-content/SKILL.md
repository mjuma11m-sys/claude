# 🧤 Goalkeeper Content

## المخرج لكل فكرة
| الحقل | مثال |
|---|---|
| الصيغة | تعليمي / تحدي / قبل-بعد / POV / ردّة فعل / فلوق |
| الهوك (0–3s) | نص على الشاشة + أول جملة + أول لقطة |
| السكربت | لقطات مرقّمة بالثواني |
| اللقطات المطلوبة | زاوية + سرعة لكل لقطة |
| CTA | سؤال للتعليقات أو "احفظه للتمرين الجاي" |
| المدة | 15–35s ريل · 6–12 دقيقة يوتيوب |

## سلاسل ناجحة
- **«خطأ يسويه كل حارس»** — خطأ ← ليش ← التصحيح (تعليمي، يتحفظ).
- **«تمرين اليوم»** — تمرين واحد، 3 مستويات صعوبة.
- **«حارس vs …»** — ضد مهاجم/صديق/جمهور، عدّاد تصديات.
- **«حلّل التصدي»** — لقطة من مباراتك أو احترافية، slow-mo + خطوط.
- **«يوم مباراة»** — فلوق: تحضير، إحماء، اللحظات، النتيجة.
- **«معدات الحارس»** — قفازات (grip، cut: negative/roll/flat)، عناية بالقفاز.
- **تحديات الجمهور** — "عطوني تسديدة أصدها".

## هوكات (قوالب)
- «90% من الحراس يغلطون هني 👇»
- «هالتمرين خلاني أصد ركلة جزاء»
- «لا تشتري قفازات قبل ما تشوف هذا»
- يبدأ بأقوى تصدي **قبل** الشرح، ثم «خلني أوريك شلون».
- رقم أو تحدي واضح: «10 تسديدات — كم أصد؟»

## التصوير
| اللقطة | الإعداد |
|---|---|
| خلف المرمى (POV) | الجوال على حامل خلف الشبكة بارتفاع ~1.2م، 4K/60 |
| من الجنب | زاوية 45° على خط المرمى — تبين الارتماء كامل |
| Slow-mo | 120fps (1080p) أو 240fps للتصدي — إضاءة قوية/نهار |
| من مستوى الأرض | للارتماءات والقفز |
| على الصدر/الرأس | POV المهاجم القادم |
- ثبّت الـ exposure والفوكس (ضغطة مطوّلة) · نظف العدسة · صوت: مايك لاسلكي للشرح.
- صوّر عمودي 9:16 واترك هامش فوق وتحت (مناطق واجهة إنستقرام).

## النشر
- 4–5 ريلز/أسبوع، 1 فيديو يوتيوب/أسبوعين، ستوريز يومي من التمرين.
- كابشن: سطر هوك + سطرين قيمة + سؤال. هاشتاقات 3–5 محددة (`#حارس_مرمى` `#goalkeeper` `#gktraining` `#البحرين`).
- راجع بعد 48 ساعة: معدل المشاهدة الكاملة والحفظ — كرر الصيغة الرابحة.
