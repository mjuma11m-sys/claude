# 📚 Daily Learning

**الحقيقة:** Claude ما يتغير بين الجلسات؛ «التعلّم» = ملاحظات موثّقة بـ `notes.md` تنقرأ وتنطبق بالجلسات الجاية.

## الجولة اليومية
1. اقرأ آخر 30 سطر من `notes.md` عشان ما تكرر.
2. دور على شي واحد جديد (آخر 30 يوم) بمجال واحد يدور بالتناوب: برمجة ← مونتاج ← محتوى/حراسة ← أعمال/قانون البحرين. استخدم WebSearch (standard).
3. اقبل المعلومة بس لو لها مصدر رسمي/موثوق ورابط. لا تخمّن، لا تنقل شي مو متأكد منه.
4. أضف مدخل واحد لـ `notes.md` بهالقالب:

```
## YYYY-MM-DD · المجال · العنوان
- **الجديد:** سطر
- **ليش يهمنا:** سطر (ربطه بمشروع: sports-admin / real-estate / ريلز)
- **تطبيق:** خطوة أو كود صغير
- **المصدر:** رابط
```
5. لو المعلومة تغيّر skill موجودة (مثلاً تغيير بـ CapCut) عدّل السطر المعني بالـ skill نفسها بدل ما تكتفي بالملاحظة.
6. `git add` + commit بالفرع الحالي + push. لا PR.

## قواعد
- مدخل واحد باليوم، أقل من 10 أسطر.
- لا تغيّر كود تطبيقات المستخدم من هالمهمة.
- لو ما لقيت شي يستاهل: اكتب «لا جديد مفيد اليوم» وانتهِ.
