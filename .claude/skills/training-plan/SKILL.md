# 🧤 Goalkeeper Training Plan

اسأل (أو افترض وقل افتراضك): المستوى · أيام المباراة · عدد الجلسات/الأسبوع · المعدات · الإصابات الحالية · الهدف (مثلاً الكرات العالية).

## الأسبوع حسب المباراة (MD)
| اليوم | التركيز | الشدة | الارتماءات |
|---|---|---|---|
| MD+1 | استشفاء: دراجة/سباحة خفيفة، mobility، foam roll | منخفضة | 0 |
| MD+2 | راحة أو تقنية خفيفة | منخفضة | ≤ 10 |
| MD-4 | قوة (جيم) + تقنية: footwork، handling | عالية | 20–30 |
| MD-3 | انفجارية: plyometrics، 1v1، الارتماء | عالية جداً | 30–40 |
| MD-2 | الكرات العالية، crossing، التوزيع، تنظيم الدفاع | متوسطة | 15–25 |
| MD-1 | سرعة وردة فعل قصيرة، تحسس الكرة | منخفضة | ≤ 10 |
| MD | إحماء المباراة (20–25 دقيقة) | — | 8–12 |
الأرقام إرشادية — قلّل 30–40% لو الحمل عالي أو فيه ألم.

## مكونات الجلسة الفنية (60–75 دقيقة)
1. **إحماء RAMP (12–15د):** jogging وskipping ← mobility للورك والكتف ← تنشيط (glute bridges، band walks) ← قفزات خفيفة وحركة قدمية.
2. **Handling (10د):** صدّ على الصدر، فوق الرأس، أرضيات — 2×10 لكل نوع.
3. **Footwork (10د):** سلم، أقماع، set position ← خطوة جانبية ← دفع. 4–6 مجموعات × 6–8 ثواني، راحة 1:4.
4. **الموضوع الرئيسي (20–25د):** ارتماء، 1v1، أو كرات عالية — جودة قبل الكمية.
5. **تحت الضغط (10د):** سيناريو مباراة (تسديدات من زوايا، rebounds).
6. **تبريد (5د).**

## ردة الفعل
- ضاغط/مدرب يرمي من خلف حاجز أو ستارة (رؤية متأخرة) · كرات التنس على الجدار · reaction ball · أضواء (BlazePod) · تسديد من مسافة 6–8م مع تغطية.
- قصير وحاد: 6–10 تكرار × 3 مجموعات، راحة كاملة بين المجموعات (الهدف السرعة، مو التعب).

## Plyometrics (MD-3، مرتين/أسبوع كحد أقصى)
| التمرين | الحجم |
|---|---|
| Lateral bounds (مع ثبات بالهبوط) | 3×6 لكل جهة |
| Box jumps (هبوط ناعم، انزل ماشي) | 4×4 |
| Skater jumps | 3×8 |
| Single-leg hops | 3×5 لكل رجل |
| Med-ball side throws | 3×6 لكل جهة |
- 60–100 لمسة أرض للجلسة · قبل الجيم · راحة 60–90s.

## القوة (MD-4، 45–60د)
| النمط | تمرين | Sets × Reps |
|---|---|---|
| Hinge | Trap-bar deadlift / RDL | 4×4–6 |
| Single-leg | Bulgarian split squat | 3×6–8 |
| Adductors | Copenhagen plank | 3×20–30s |
| Push | DB bench / push-up | 3×6–8 |
| Pull | Pull-up / row | 3×6–8 |
| Core anti-rotation | Pallof press | 3×10 |
| Shoulders | external rotation بالمطاط | 2×15 |
| Neck/wrist | grip وwrist curls | 2×15 |

## الوقاية والاستشفاء
- **أكثر الإصابات:** الأصابع، الكتف، أسفل الظهر، الورك/المقربة، الركبة ← تمارين الكتف والـ adductors ثابتة أسبوعياً.
- النوم 8–9 ساعات · بروتين 1.6–2.2 g/kg/يوم · ترطيب (حرارة البحرين: 500–750ml/ساعة تمرين + إلكترولايت في الصيف).
- **علامات التوقف:** ألم حاد أو موضعي، تورم، ألم ليلي ← وقف التمرين وراجع أخصائي علاج طبيعي.

## المخرج
جدول أسبوعي (يوم · الهدف · التمارين · الحجم · الشدة RPE 1–10) + نسخة جلسة مفصّلة لليوم المطلوب + كيف تتدرّج كل أسبوع (+10% حجم أو صعوبة، وأسبوع تخفيف كل 4).
