# شعارات الأندية

ضع هنا ملف شعار كل نادٍ باسم الـslug (مثال: `al-riffa.png`)، والأسماء في `src/data/bhclubs.ts`.
التطبيق يلتقطها تلقائياً: لما يكتب الإداري اسم النادي كخصم أو كناديه تظهر الشعار على بطاقة المباراة.

- الصيغ: png أو webp أو svg، مربّعة تقريباً، حتى 256 بكسل.
- **الشعارات علامات تجارية لأصحابها.** لا تضف إلا ما عندك إذن مكتوب باستخدامه من النادي (أو النادي نفسه يرسله).
- لو المجلد فاضي، تطلع حرف النادي الأول بدل الشعار، ويقدر الإداري يرفع الشعار بنفسه.
