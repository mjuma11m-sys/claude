# هوية «حياتي» — لؤلؤ وبحر

**الفكرة:** البحرين = بحر ولؤلؤ. الشعار «ح» داخل قوس مفتوح = مسار يومك من الفجر للعشا، والنقطة المرجانية = أنت الحين بيومك.

## الشعار
«ح» داخل قوس مفتوح (مسار يومك) + نقطة مرجانية (أنت الحين). الملفات تنبني بـ `node brand/build.js` ← `brand/out/`.

| الملف | متى |
|---|---|
| `mark-app-icon` (.svg + 1024.png) | الأساسي: أيقونة التطبيق، صورة البروفايل |
| `mark-on-light` | على أبيض أو لؤلؤي أو ورق |
| `mark-on-dark` | على بحري أو صورة غامقة |
| `mark-mono-sea` | لون واحد: طباعة، ختم، تطريز |
| `mark-mono-white` | لون واحد فوق صورة أو فيديو |
| `lockup-horizontal-light/dark.png` | الشعار + «حياتي / HAYATI» جنب بعض: بانر، أول الفيديو، الموقع |
| `lockup-stacked-light/dark.png` | الشعار فوق الاسم: بوست مربع، آخر الفيديو، ستوري |
| `icon-square.svg` → `../icons/*.png` | مصدر أيقونات المتاجر (iOS/Android يقصّون الزوايا بنفسهم) |

- **الاسم المكتوب:** «حياتي» IBM Plex Sans Arabic **700**، وتحته «HAYATI» **700** بحروف كبيرة ومسافة `0.08em`، بلون أفتح (`--brand` على فاتح، لؤلؤي 70% على غامق).
- **مساحة فاضية** حول الشعار = ربع عرضه على الأقل. **أصغر مقاس:** 24px بالشاشة، 10mm بالطباعة.
- **ممنوع:** تغيير الألوان، المد، الظل، التدوير، أو حط الشعار على خلفية مزحومة بدون النسخة الأحادية.

## الخط
**IBM Plex Sans Arabic** (Google Fonts، رخصة SIL OFL 1.1): عربي وإنجليزي بنفس العائلة.

| الوزن | الاستخدام |
|---|---|
| 400 | النص |
| 500 | التسميات |
| 600 | عناوين صغيرة، أزرار |
| 700 | العناوين، الأرقام الكبيرة، الاسم المكتوب |

| المقاس | Token | وين |
|---|---|---|
| 34 | `--fs-display` | الرقم الكبير بالبطاقة الرئيسية |
| 28 | `--fs-h1` | عنوان الشاشة |
| 22 | `--fs-h2` | عنوان قسم |
| 17 | `--fs-h3` | عنوان بطاقة، عنصر قائمة |
| 15 | `--fs-body` | النص |
| 13 | `--fs-small` | التفاصيل |
| 11 | `--fs-micro` | التبويبات، تسميات صغيرة |

- الأرقام: `tabular-nums` واتجاهها LTR، والعملة «د.ب» بحجم 0.62em.
- **بالفيديو والبوستات:** 700 للعنوان (90px+ على 1080)، و400 للسطر الثاني، وأصغر شي 38px.

## الحركة
- `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)` للدخول والخروج.
- `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)` للنوافذ.
- حركات الواجهة تحت 300ms، والتفاصيل في `../js/features/motion.js`.

## للفيديوهات والريلز
خلفية `#0E3B43` ونص `#E8DCC4` ولمسة مرجانية `#FF6B4A` وحدة بكل لقطة. الخط نفسه، والشعار بآخر الفيديو.
