# هوية «حياتي» — لؤلؤ وبحر

**الفكرة:** البحرين = بحر ولؤلؤ. الشعار «ح» داخل قوس مفتوح = مسار يومك من الفجر للعشا، والنقطة المرجانية = أنت الحين بيومك.

## الشعار
| ملف | الاستخدام |
|---|---|
| `mark.svg` | الشعار الأساسي (زوايا دائرية) |
| `icon-square.svg` | مصدر أيقونات التطبيق (iOS/Android يقصّون الزوايا بنفسهم) |
| `../icons/*.png` | 512 / 192 / 180 (apple-touch) |

- مساحة فاضية حول الشعار = ربع عرضه على الأقل.
- لا تغيّر ألوان الشعار، ولا تمدده، ولا تحط عليه ظل.

## الألوان
| Token | Light | Dark | الاستخدام |
|---|---|---|---|
| `--sea` | `#0E3B43` | — | الأساسي: البطاقة الرئيسية، الشعار |
| `--pearl` | `#E8DCC4` | — | لون «ح» بالشعار، ونقطة «الحين» |
| `--coral` | `#FF6B4A` | — | زر الإضافة فقط + نقطة الشعار (قليل = قوي) |
| `--brand` | `#13636B` | `#6EC5C0` | الروابط، التبويب المختار، الأزرار |
| `--bg` | `#F7F4EE` | `#0A1A1E` | الخلفية |
| `--surface` | `#FFFFFF` | `#10262B` | البطاقات |
| `--text` | `#0B2328` | `#EFE8DA` | النص |
| `--income` | `#2F9E7A` | `#4FC79E` | الدخل |
| `--expense` | `#D63A3A` | `#FF7A6B` | الصرف والتنبيهات |
| tint | `#1A8A8F` | `#1A8A8F` | أيقونات البطاقات الصغيرة |

**القاعدة:** المرجاني للفعل الأساسي بس (زر +). لا تستخدمه للصرف، ولا تخلّيه يتكرر بنفس الشاشة.

## الخط
- **IBM Plex Sans Arabic** بأوزان 400 / 500 / 600 / 700.
- الأرقام: `tabular-nums` واتجاهها LTR، والعملة «د.ب» بحجم 0.62em.

## الحركة
- `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)` للدخول والخروج.
- `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)` للنوافذ.
- حركات الواجهة تحت 300ms، والتفاصيل في `../motion.js`.

## للفيديوهات والريلز
خلفية `#0E3B43` ونص `#E8DCC4` ولمسة مرجانية `#FF6B4A` وحدة بكل لقطة. الخط نفسه، والشعار بآخر الفيديو.
