# قائمة قبل أي رفع للمتجر (DW-084)

> انولدت من رفضين من Apple (0.25 و0.26): مشاكل ما كانت تبين بالاختبارات الآلية، بس على جهاز حقيقي أو بإعدادات App Store Connect.
> ما ينرفع شي قبل ما كل بند هني يصير ✅.

## 1. الكود (عليّ)
- [ ] `npm run test:unit` و`npx playwright test` كلها خضرا.
- [ ] رقم النسخة نفسه بكل مكان: `app.js` · `sw.js` · `build.gradle` · `project.pbxproj` (الاختبار يتأكد).
- [ ] «جديد بحياتي» فيه بس الأشياء اللي تشتغل اليوم.
- [ ] ما فيه أي صلاحية (entitlement أو Info.plist) لميزة مو مستخدمة (درس HealthKit).

## 2. على الأجهزة (عليك، 15 دقيقة)
| الجهاز | جرّب |
|---|---|
| **iPad Simulator** (iPad Air 11") | أول شاشة · حساب جديد · دخول · تابع مع Apple · تابع مع Google · احذف كل بياناتي |
| **آيفونك** (من Xcode ▶︎) | نفس الأشياء + تسجيل محاضرة وقفل الشاشة + اقرأ أي ملف |
- [ ] امسح التطبيق قبل، عشان تجرّب مثل مستخدم جديد (Apple تطلب كذا).

## 3. App Store Connect (عليك)
- [ ] **Build** المختار = آخر build، ورقم النسخة نفسه.
- [ ] **Sign-In Information**: الحساب التجريبي **دخلت فيه بنفسك اليوم** بنفس الإيميل وكلمة السر بالضبط (درس mjuma13 / raview).
- [ ] الحساب التجريبي: إيميل مأكد، **بدون** تحقق بخطوتين.
- [ ] **Notes** و**Description** ما تذكر شي انشال (مثل Apple Health).
- [ ] App Privacy يطابق الكود.

## 4. الإرسال
