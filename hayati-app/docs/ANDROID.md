# «حياتي» على أندرويد (Capacitor)

> **DW-008 (شركة الديوانية):** نفس كود الآيفون، داخل تطبيق أندرويد أصلي. فيه التذكيرات الذكية وأزرار التنبيه («✓ خلصته»، «⏰ بعد ساعة»، «✓ حضرت») والتطبيق مسكّر، والاهتزاز، والمشاركة، والدخول بـ Apple وGoogle.

## يختبر نفسه
كل تحديث على GitHub (`.github/workflows/hayati-android.yml`):
1. يبني APK (`scripts/android-build.sh`).
2. يشغّل محاكي أندرويد 14، يثبّت التطبيق ويفتحه، ويصوّر الشاشة (`scripts/android-smoke.sh`).
3. يفشل لو البناء انكسر، أو التطبيق طاح، أو الشاشة سودا أو فاضية. الصورة والسجل ينحفظون مع كل تشغيل (Artifacts ← `android-screenshot`).

## على جهازك
```bash
cd hayati-app
npm install
npm run cap:sync:android     # كل ما تغيّر شي بملفات التطبيق
npm run cap:open:android     # Android Studio ← ▶️
```
خطوات المتجر بالتفصيل: `docs/STORE.md` ← «Google Play».

## الفرق عن الآيفون
| | أندرويد | آيفون |
|---|---|---|
| إذن التنبيهات | يطلبه أول ما يصير فيه شي ينبّه عليه (أندرويد 13+) | نفس الشي |
| التنبيه بالدقيقة | `SCHEDULE_EXACT_ALARM`. على أندرويد 14 لو المستخدم ما وافق، ممكن يتأخر دقايق | بالدقيقة |
| زر الرجوع | يسكّر النافذة، بعدها يرجع لـ «اليوم»، بعدها يصغّر التطبيق | — |
| أيقونة التنبيه | «ح» بيضا (`ic_stat_hayati`)، أندرويد يلوّنها | أيقونة التطبيق |
| رسالة البنك | **شارك ← حياتي** من تطبيق الرسائل: نافذة اللصق تنفتح معبّاة (بعد الموافقة أول مرة، وبعد الرمز لو مقفول). ما ينحفظ شي إلا بـ «إضافة»، ولا نطلب `READ_SMS` | الصق (مشاركة الآيفون تحتاج Share Extension، بعدين) |

## الأيقونات وشاشة البداية
من نفس الشعار: `node brand/android-res.js` يطلّعها كلها لـ `android/app/src/main/res/`.

## لا تسوي
- لا تعدّل `android/app/src/main/assets/public/`: تنمسح مع كل `cap:sync:android`.
- لا تحط مفتاح التوقيع (`.jks`) داخل `hayati-app`. الريبو يرفضه أصلاً.
- لا تضيف `USE_EXACT_ALARM`: Google Play يحصره بتطبيقات المنبّه والتقويم، وفيه اختبار يمنعه.
