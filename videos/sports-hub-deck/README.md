# عرض Sports Hub (PowerPoint)

- `sports-hub-deck.pptx`: 13 شريحة 16:9، عربي RTL، نصوص حقيقية قابلة للتعديل. `sports-hub-deck.pdf`: نفس العرض جاهز للإرسال.
- الخط **Tajawal**: ثبّت الملفات من `fonts/` (انقر مرتين ← تثبيت) قبل فتح الـpptx، وإلا يستبدله البرنامج بخط ثاني.
- اللقطات من النسخة التجريبية ببيانات خيالية (مكتوب عليها بكل شريحة). لإعادة التصوير: شغّل `shoot.cjs` على نسخة مبنية (`npx vite preview --port 4399`) ثم قصّ اللقطات في `crops/` وشغّل `python3 build_deck.py crops sports-hub-deck.pptx`.
