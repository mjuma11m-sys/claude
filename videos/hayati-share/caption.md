# ريل «شارك ← حياتي»

> جلسة الديوانية: `videos/diwaniya-skill/sessions/hayati-share-video.html`. الميزة من شركة الديوانية (`DW-009`)، ونسخة أندرويد (`DW-008`).

## الملفات
| | |
|---|---|
| `hayati-share.mp4` | الريل النهائي، 1080×1920، 60fps، 24 ث، مع الموسيقى |
| `cover.jpg` | الكفر (فريم 12.3 ث: «انضافت ✓»)، والمهم داخل المربع 1:1 بالنص |
| `scene.html` | المشاهد (كل حركة دالة بالوقت `setT(t)`) |
| `shots.js` + `shots/` | لقطات حقيقية من التطبيق (`dist/Hayati.html`) ببيانات تجريبية، عن طريق نفس كود المشاركة |
| `render.js` | `node render.js` يطلّع `silent.mp4`، و`node render.js preview 7.4 12.3` لقطات معاينة |
| `music.py` | موسيقى مولّدة بالكود (ما فيها حقوق) |

```bash
node shots.js && node render.js
ffmpeg -y -i silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart hayati-share.mp4
```
