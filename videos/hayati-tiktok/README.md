## الفيديوهات الجاهزة لتيك توك
تيك توك يغطي **يمين الشاشة** (الأزرار) و**تحت** (الكابشن والصوت) و**فوق** (التبويبات). عشان كذا هالنسخ كل محتواها مصغّر داخل المنطقة الآمنة، والخلفية كاملة. **لا ترفع نسخ إنستقرام نفسها بتيك توك.**

| الملف | ينزل |
|---|---|
| `tiktok-promo.mp4` | أول فيديو |
| `tiktok-bank-sms.mp4` | بعده بيومين |

## وش يختلف بتيك توك
| | إنستقرام | تيك توك |
|---|---|---|
| **الناس** | يعرفونك (ربعك أول) | غرباء، والخوارزمية تقرر |
| **الهوك** | ثانيتين | **ثانية وحدة**، والكلام من أول فريم |
| **الوتيرة** | 3 بالأسبوع | **4–5 بالأسبوع**، والأقصر أحسن (15–30 ث) |
| **البحث** | هاشتاقات | **كلمات بحث بالكابشن والكلام**، لأن تيك توك صار محرك بحث |
| **الرد** | تعليق نصي | **رد بفيديو على التعليق**، وهذا أقوى شي بتيك توك |

## 🔥 أفكار تيك توك بالذات
| # | الفكرة | ليش تناسب تيك توك |
|---|---|---|
| 1 | **«أبني تطبيقي — اليوم X»**: سلسلة يومية 15 ث، شاشة الكود أو التطبيق + وش سويت اليوم | الناس تتابع السلسلة، واسمها بالتعليقات: «وش صار باليوم 5؟» |
| 2 | **«رد بفيديو»**: أي تعليق فيه اقتراح ← فيديو رد: «اقترحت كذا، هذي جلسة الديوانية عليه» | تيك توك يوزّع الردود بالفيديو، وهي نفس حملة «سوّ ميزتك» |
| 3 | **«يوم بحياة طالب وحارس مرمى بحريني»**: محاضرة ← تمرين ← مذاكرة، والتطبيق بين كل وحدة | محتوى حياة حقيقي، وجهك = ثقة |
| 4 | **جلسة الديوانية المتحركة**: تسجيل شاشة لجلسة حقيقية + «قبل كل ميزة، نقاش بالذكاء الاصطناعي» | شكل جديد ما ينشاف كثير |
| 5 | **«هل يقدر يقرا رسالة بنكي؟»**: تجرب رسايل بنوك بحرينية مختلفة (أرقام البطاقة مخفية) | تفاعل: «جرّب بنكي!» |

## الأوقات (البحرين)
