## ترتيب النشر
1. حط صورة البروفايل والبايو.
2. انشر البوستات الثلاث **بالعكس**: 3 ← 2 ← 1، عشان يطلع التعريف أول واحد بالشبكة.
3. بعدها الريل بالكفر (8–10 مساءً).
4. الهايلايت: انشر ستوري لكل وحدة، وثبّتها بالغلاف من «تعديل الهايلايت» ← «تعديل الغلاف».
