# «سوّ ميزتك» — قالب الريل الأسبوعي

كل أسبوع: اقتراح من التعليقات ← جلسة ديوانية ← الميزة تنبني ← ريل 14 ث باسم صاحب الاقتراح.

## الخطوات
1. خذ **موافقة** صاحب الاقتراح إنك تذكر حسابه (رسالة خاص: «بنذكر حسابك بالريل، أوكي؟»).
2. لقطة شاشة للميزة الجديدة (1170×2532 من الآيفون، أو اطلبها مني).
3. انسخ `config.json` وعدّله:
   ```json
   { "user": "@اسم.حسابه", "suggestion": "نص اقتراحه", "feature": "اسم الميزة", "screen": "مسار اللقطة", "week": 2 }
   ```
4. `node render.js config-week2.json` ← `feature-week2.mp4`

`config.json` الحالي **مثال بس** (@your.friend) — لا تنشره.
