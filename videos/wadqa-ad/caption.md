# إعلان «ودقة · WADQA»

> جلسة الديوانية: `videos/diwaniya-skill/sessions/wadqa-ad.html`

| | |
|---|---|
| `wadqa-ad.mp4` | الإعلان النهائي، 1080×1920، 30fps، 20 ث، مع الموسيقى |
| `scene.html` | المشاهد (كل حركة دالة بالوقت `setT(t)`) |
| `render.js` | `node render.js` يطلّع `silent.mp4`، و`node render.js preview 1.8 8.3` لقطات معاينة |
| `music.py` | موسيقى مولّدة بالكود (ما فيها حقوق) |

بعد `render.js`:
```bash
ffmpeg -y -i silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart wadqa-ad.mp4
```

## التسلسل (ولا قطعة)
| الوقت | المشهد |

| 0–2.7 | قطرة تنزل وتموّج + «تطبيقاتك تعرف عنك كثير. وين تروح **بياناتك**؟» |

| 14–20 | القطرة تنرسم، النقطة الذهبية تنزل فيها ← ودقة · WADQA STUDIO · صافية مثل المطر |
