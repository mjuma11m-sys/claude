# ريل «حياتي» — أسلوب الموشن

> جلسة الديوانية «حلّل أسلوب الموشن وطبّقه». الميكانيكا مأخوذة من تحليل إعلان مرجعي، والمحتوى والهوية كلها «حياتي».

## الملفات
| | |
|---|---|
| `hayati-motion.mp4` | الريل النهائي، 1080×1920، 60fps، 30 ث، مع الموسيقى |
| `scene.html` | المشاهد (كل حركة دالة بالوقت `setT(t)`) |
| `render.js` | `node render.js` يطلّع `silent.mp4`، و`node render.js preview 5 12.8` لقطات معاينة |
| `music.py` | موسيقى مولّدة بالكود (ما فيها حقوق) |

بعد `render.js`:
```bash
ffmpeg -y -i silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart hayati-motion.mp4
```

## الأسلوب (من التحليل) ← وين طبقناه
| بالمرجع | بـ «حياتي» |
|---|---|
| 6 قطعات بس بـ 89 ث، كل انتقال حركة | ولا قطعة: كبسولة تصغر، أشرطة درج، دائرة من الضغطة، نقطة تطير |
| ورق دافي + إضاءة ملونة تتغير كل قصة | `#F7F4EE` + خوخي ← نعناعي ← بنفسجي |
| كلمة كلمة، والمهمة بلون واحد قوي | المرجاني `#FF6B4A` للكلمة المهمة (كبيرة بس) |
| فقاعة تنكتب + فقاعة ترد + تسمية `// …` | «كم صرفت على كوستا؟» ← «اكتب اسم المحل.» · «حياتي // سؤال اليوم» |
| جوال 2D + 3 سطور تنبني + يد تضغط | لقطة البحث + «اكتب. يطلع المجموع.» |
| رقم كبير يعد | **45** اختبار قبل كل تحديث (رقم حقيقي) |
| نقطة تصير الشعار | نقطة زر «+» تطير وتصير نقطة «ح» بالشعار |
