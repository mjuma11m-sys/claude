## 2. عليك (بالترتيب)
1. **Supabase → SQL Editor:** الصق `docs/company/store/supabase-delete-account.sql` واضغط Run. (بدونه زر «احذف حسابي» يطلع خطأ. أداة الربط وقفت عند أمر الحذف وتنتظر موافقتك، عشان كذا ما انطبق تلقائياً.)
2. **حساب Google Play Console:** 25$ مرة وحدة. فرد أو منظمة (المنظمة تحتاج D-U-N-S).
3. **حساب Apple Developer:** 99$/سنة. فرد = اسمك الشخصي يطلع بائع. منظمة (WADQA) = سجل تجاري + D-U-N-S.
4. **الدومين** (مستحسن قبل المتجر): رابط الخصوصية والدعم يكون ثابت.
5. **المحامي**: قبل «إرسال للمراجعة» العامة.
