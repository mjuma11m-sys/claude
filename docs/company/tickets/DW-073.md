# DW-073 · الدخول عبر Google وApple

- **الأولوية:** P2 · **فُتحت:** 2026-10-23

المالك: «أضف تسجيل الدخول عن طريق أبل أو قوقل». الديوانية: `videos/diwaniya-skill/sessions/sports-hub-social-login.html`.

سُلّم: زرّا «تابع مع Google/Apple» بشاشة الدخول (`signInWithOAuth`)، يظهران فقط مع `VITE_AUTH_GOOGLE/APPLE=true`؛ بدون مهاجرة (نفس trigger الملف الشخصي)؛ تحديث سياسة الخصوصية؛ `sports-hub-app/AUTH-PROVIDERS.md` (إعداد Google Cloud وApple Developer وSupabase)؛ اختبارات وحدة وlogin-real (الضغط يوجّه لـ`/auth/v1/authorize?provider=google` وrediect للأصل). لقطة: `videos/login-google-apple.png`.

**ما لم يُختبر:** الدخول الفعلي مع Google/Apple (يحتاج إعداد لوحاتك وبيئة حقيقية). Apple تحتاج حساب مطوّر مدفوع وتجديد السر كل 6 أشهر.
مخاطرة موثّقة: «إخفاء بريدي» من أبل لا يطابق `admin_provision_staff` بالإيميل.
