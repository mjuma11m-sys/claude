# الدعوة وخطة التجربة

## رسالة الدعوة (واتساب)
> أسوي تجربة مجانية لبرنامج تمارين مخصص لحراس المرمى (3 أيام بالأسبوع، أسبوعين). أبي 10 حراس يجربونه ويقولون لي رأيهم بصراحة. لازم يكون عندك 3 شهور تدريب بالأوزان على الأقل، وتعبّي استبيان جاهزية وموافقة قبل. مو بديل للطبيب أو مدربك. تبي تشارك؟

## الجدول
| متى | وش |
|---|---|
| قبل البدء | مراجعة البرنامج والموافقة (مختص تدريب + المالك) ← **بوابة إلزامية** |
| يوم 0 | استبيان + موافقة لكل مشارك، تعبئة `03-tracking.csv` |
| يوم 1–14 | المشارك يرسل بعد كل جلسة: ✅/❌ + RPE + هل فيه ألم |
| يوم 14 | 3 أسئلة: وش أعجبك؟ وش وقّفك؟ تدفع كم (BHD)؟ |
