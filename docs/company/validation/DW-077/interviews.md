# DW-077 — أسئلة التحقق

## مقابلة صاحب/مدير ملعب (15 دقيقة)
1. كيف تستقبل الحجوزات الحين؟ (واتساب، اتصال، دفتر)
2. كم حجز بالأسبوع؟ وأي ساعات الأكثر ازدحاماً؟
3. كم مرة صار حجز مزدوج أو لخبطة آخر شهرين؟
4. نسبة الغياب بدون إلغاء؟ وش تسوي فيها؟
5. وش أكثر شي يتعبك بإدارة الحجز؟
6. لو أعطيتك رابط حجز مجاني تجربة أسبوعين، تجرب؟
7. لو نفع، كم تدفع بالشهر؟ (لا تعطيه رقماً قبل ما يجاوب)
8. هل تستقبل مجموعات أطفال أو أكاديميات؟

## استبيان لاعب (دقيقتين)
1. كم مرة تلعب بالشهر بملعب مدفوع؟
2. كيف تحجز الحين؟ وش أسوأ تجربة؟
3. تفضل رابط تحجز منه بنفسك أو تكلم الملعب؟
4. هل مرّت عليك مرة ينقصكم لاعب؟ كيف حليتوها؟
5. لو فيه لوحة «ناقصنا لاعب»، تستخدمها؟

**قاعدة:** نسجل الأجوبة كما هي، ونرفض نسأل أسئلة توجيهية («ألا تتمنى...؟»).
