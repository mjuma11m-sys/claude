## قبل أي رد على متجر (إلزامي — درس رفض 0.26)
1. الرد مكتوب بمكان واحد: `docs/APP-REVIEW-REPLY.md` بمستودع المنتج (الأحدث فوق).
2. `npm run test:unit` أخضر، ومنه `store-preflight`: الرقم نفسه بكل مكان، الرد يذكر نفس النسخة، وما يناقض أزرار الدخول أو HealthKit.
3. الـ build نفسه مختار بالنسخة وحالته Complete بـ TestFlight.
4. الحساب التجريبي انجرّب **بنفس اليوم** على جهاز حقيقي (دخول وخروج)، وبدون 2FA.
5. ما فيه كلمة سر بالرد (تنكتب بـ Sign-In Information بس).
6. المالك يضغط Submit بنفسه.
